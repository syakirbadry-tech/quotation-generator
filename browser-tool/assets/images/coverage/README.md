# Annual coverage limit images

Used on sections about the plan's annual claim limit. Keyed by the numeric annual limit amount with all non-digit characters stripped - e.g. an annual limit of "RM1,200,000" is looked up as manifest key `coverage.1200000`. Consider: imagery that conveys scale/security (a calm hospital corridor, a family leaving a hospital together) rather than anything literally depicting money.

See the [top-level assets README](../README.md) for sizing guidance,
how the manifest/fallback system works, and how to add a new image
without touching any code.
