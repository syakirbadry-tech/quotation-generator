# Miscellaneous images

A catch-all for any future image that doesn't fit an existing category (manifest category: `misc`, any key you choose). Add a new key under `misc` in image-manifest.json and call `AssetManager.getMiscImage(key)` from the renderer - no other code changes needed.

See the [top-level assets README](../README.md) for sizing guidance,
how the manifest/fallback system works, and how to add a new image
without touching any code.
