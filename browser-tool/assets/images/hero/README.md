# Hero image

The very first full-screen section of every quotation - the client's name and the agent's opening line. One image only (manifest key: `hero.default`). Something warm and universal (a family, a handshake, a calm interior) - not tied to any specific plan or product, since this is the very first thing every client sees regardless of what they're being quoted.

See the [top-level assets README](../README.md) for sizing guidance,
how the manifest/fallback system works, and how to add a new image
without touching any code.
