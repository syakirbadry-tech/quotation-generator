# Room & Board images

Used on the Ken Burns section illustrating the client's daily hospital room & board benefit. Keyed by the numeric daily rate with all non-digit characters stripped - e.g. "RM200 per day" is looked up as manifest key `roomBoard.200`. Consider: an actual hospital room/ward interior appropriate to that rate tier (a shared ward for a lower rate, a private room for a higher one).

See the [top-level assets README](../README.md) for sizing guidance,
how the manifest/fallback system works, and how to add a new image
without touching any code.
